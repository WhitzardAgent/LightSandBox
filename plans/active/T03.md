## 目标与边界(用户指令)

把 2026-09-23 已有 Host Probe 整理成项目规定的 **HostReport**(机器可读),
逐能力记录 userns / uid mappings / cgroup / procfs / mount / rootfs / network /
seccomp / LSM / filesystem / resource,状态 ∈ {SUPPORTED, DEGRADED, UNSUPPORTED,
NOT_TESTED},每项绑定 evidence command + exit code + important output。
不重复整套探索;但每条能力状态均由**现场重跑的最小只读 argv 探针**重新测量
(可重复、状态可复算),不是把旧文本复制成结论。

## 事实与产物

- 报告:`evidence/host/hostreport-v1.json`(schema lightsandbox.hostreport/1),
  生成器 `python/src/lightsandbox_dev/host_probe.py`,校验器
  `lightsandbox_dev.capability_report`(与 ls-core 类型对齐)。
- `specs/host-profiles.json` 新增 `portable-rootless` profile:observed=true,
  绑定报告路径 + sha256 + capabilities_summary + 禁止声明清单;原有三个
  profile 原样保留。
- 实测状态(2026-09-24,本宿主):
  SUPPORTED: userns, mount(tmpfs/bind,ctypes mount(2) 命名空间内验证)
  DEGRADED: uid_mappings(单 ID,无 subuid/newuidmap)、rootfs(磁盘 overlay upper
    拒、无 fuse ⇒ 仅 FULL_COPY/TMPFS_COW)、network(netns 仅 lo,无 helper)、
    seccomp(内核支持但静态 runc 无 libseccomp)、lsm(AppArmor 激活不可管理)、
    filesystem(/dev/fuse 缺,根 fs=overlayfs)
  UNSUPPORTED: cgroup(ro,EROFS ⇒ 硬限额禁止声明)、procfs(EPERM ⇒
    私有 /proc 不可建)、resource(无 user 委托;RLIMIT 仅护栏)
- 探针修正的两个测量实现 bug(非宿主事实):bind 内容原在 namespace 销毁后
  验证(改由命名空间内一次性 ctypes 探针内验证);netns 接口原读
  /sys/class/net(挂在旧 ns 的 sysfs,看到宿主接口,改读 netns 感知的
  /proc/net/dev)。
