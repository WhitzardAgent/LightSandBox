## 命令与证据

当前可以执行：

```bash
python3 tools/packctl.py validate
python3 dev/check_native.py
python3 dev/check_seeds.py
```

产品runner由T00实现。完成后本任务使用：

```bash
./dev/check unit
./dev/check runtime --task T00 --worker WORKER_ID
./dev/check differential --task T00 --worker WORKER_ID
```

后两条需实际授权worker；本包没有这些产品命令，不能以echo或mock替代。特定本地合同任务先用真实跨语言/协议fixture，runtime层条件不具备时如实阻塞。
