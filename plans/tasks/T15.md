

## 评审与失败交接

helper可读文件权限与用户shell一致；openat2缺失时需要成熟安全fallback或拒绝相应路径。

失败交接包含最小输入、预期/实际、实际文件/命令、原始结果、残留资源、已排除原因和下一项调查。共享合同、锁文件和判据只由指定集成者变更。
