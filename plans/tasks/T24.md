- [ ] 运行相关真实层与全部本地测试，保存原始日志/退出码/收集数。无权限或资产记blocked，不修改判据。

## 命令与证据

当前可以执行：

```bash
python3 tools/packctl.py validate
python3 dev/check_native.py
python3 dev/check_seeds.py
```

产品runner由T00实现。完成后本任务使用：

```bash
./dev/check unit
./dev/check runtime --task T24 --worker WORKER_ID
./dev/check differential --task T24 --worker WORKER_ID
```

后两条需实际授权worker；本包没有这些产品命令，不能以echo或mock替代。特定本地合同任务先用真实跨语言/协议fixture，runtime层条件不具备时如实阻塞。

## 评审与失败交接

训练模型不参与一致性门禁，模型没解出来不等于沙盒不兼容。

失败交接包含最小输入、预期/实际、实际文件/命令、原始结果、残留资源、已排除原因和下一项调查。共享合同、锁文件和判据只由指定集成者变更。
