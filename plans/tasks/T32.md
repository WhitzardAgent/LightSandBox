## 执行步骤

- [ ] 查看Git状态、任务依赖和源锁。只读本任务必要上下文，保留用户已有工作。
- [ ] 将下表输入/操作/观察固化为真实测试，先得到与目标缺失相关的失败。
- [ ] 在发行commit重验锁与任务manifest，运行完整目标套件和负控；确认host/API版本支持范围。
- [ ] 从原始证据重算全量执行、正向oracle与一致性比例；保留所有未解决项。
- [ ] 只有无阻塞且SLO/安全/安装满足才签发，文档不得暗示未测平台/版本也100%。
- [ ] 运行相关真实层与全部本地测试，保存原始日志/退出码/收集数。无权限或资产记blocked，不修改判据。
- [ ] 自审diff并独立review，提交后按handoff模板交接；未经验证不改verified。

## 命令与证据

当前可以执行：

```bash
python3 tools/packctl.py validate
python3 dev/check_native.py
python3 dev/check_seeds.py
```

产品runner由T00实现。完成后本任务使用：

```bash
./dev/check unit
./dev/check runtime --task T32 --worker WORKER_ID
./dev/check differential --task T32 --worker WORKER_ID
```

后两条需实际授权worker；本包没有这些产品命令，不能以echo或mock替代。特定本地合同任务先用真实跨语言/协议fixture，runtime层条件不具备时如实阻塞。
