## Architecture Decisions(ADR 0001)

**选项 B:native rootless runc 可行,v1 = native rootless runc + 显式降级。**
未选:A(全 parity 不诚实)/ C(替代 launcher 不需要;supervisor 是补充)/ D(PRoot 触发条件未满足;
GPL-2.0 仅可选外部后端)/ E(被隔离矩阵证伪)。

必须进合同的显式降级(不得静默):① tier=PORTABLE_ROOTLESS;② single-ID,多 UID BROKEN 如实报告,
`SingleIdCompatibilityPolicy` 显式开关;③ HardResourceLimits=UNSUPPORTED(RLIMIT 仅进程级护栏);
④ /proc rbind-ro 宿主 proc,版本化 policy;⑤ 静态 runc 无 seccomp 过滤;⑥ network=none;
⑦ supervisor 架构块(runc detached 无驻留监督 → per-sandbox 轻量 supervisor 是 T04 前置)。

## Known Degradations

1. tier=PORTABLE_ROOTLESS:不发普通 Benchmark Task Parity / General Docker Semantic Parity 声明
2. single-ID userns:多 UID 镜像工作负载 BROKEN(chown/su/USER 1000);未发现 single-ID 镜像 security boundary 漂移
3. HardResourceLimits=UNSUPPORTED;RLIMIT 只能叫 process guardrail
4. /proc 策略 = rbind-ro 宿主 proc(版本化合同字段);**integrity OK,confidentiality 未证明**(见下)
5. 静态 runc(CGO_ENABLED=0)无 seccomp 过滤 = SECURITY DEGRADED(非既有功能缺失)
6. network=none 为止;pasta/slirp4netns 不阻塞主承诺,未做
7. runc detached 载荷 ppid=1,无生命周期监督/权威后台退出状态/挂起点

## Security Findings

- euid=0 伪造 rootless 会走 rootful cgroupfs 路径 → EROFS 卡死;已禁止,所有沙箱以真实 uid 65534 运行
- 宿主进程窥探:environ EPERM、kill/ptrace ESRCH;**但 cmdline/fd 计数等 /proc 元数据跨边界可见**
- ⚠️ 诚实性保留项:Round-01 的"environ 不泄漏"仅证明 **userns 内(non-dumpable)目标**与
  **跨 uid 目标**两类情形;**两个 sandbox 同为宿主 uid 65534 的同 uid 交叉情形未经专项测量**。
  ADR 0001 中若存在"不泄露秘密"式笼统结论需在 Round 02 P2.1 后修订(proc confidentiality matrix)。
- single-ID:setuid 仅 EMULATED;"只允许 root、映射 uid 0"的镜像未见边界漂移,但这也只是当前样本。
