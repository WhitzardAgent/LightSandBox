## Architecture Reframe (user directive, round-03)

- `runc != LightSandbox`. runc is the **Native backend** only.
- LightSandbox = capability-adaptive multi-backend runtime:
  `Capability Planner → { NativeRuncBackend, UmlBackend, (future) GvisorBackend, QemuTcgBackend fallback }`.
- Backend priority: 1) Native/rootless runc 2) Kernel/UML 3) Machine/QEMU TCG 4) Sentry/gVisor (deferred).
- Selection by CapabilityRequirements (multi_uid, private_proc, full_init_system, …), not by user naming a runtime.
- HostKind {VM, CONTAINERIZED, BARE_METAL} is a separate dimension from PrivilegeTier {PORTABLE_ROOTLESS, FULL_ROOTLESS, ROOTFUL}.
  This worker: **HostKind=CONTAINERIZED, PrivilegeTier=PORTABLE_ROOTLESS**.
- OCI image remains the single canonical workload format (Native→rootfs, UML→base UBD disk, QEMU→machine disk).
