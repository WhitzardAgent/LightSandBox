## Architecture Decisions

- Guest witness protocol v2.1: degrade-with-evidence over fail-fast for
  supervision (SpawnFailure reserved for genuinely unspawnable payloads).
  Degraded modes always mark `residual_risk` honestly; fork-bomb overrun of
  the drain window ⇒ `residual_risk=true`, never hidden.
- Receipt evolution stays inside the repo-owned protocol surface (non-frozen):
  host/guest ship supervision together; supervision is receipt evidence, not
  domain-model state.
- blocked ≠ delete-criterion applied to T11-C01: host capability premise
  (nested pidns) falsified live ⇒ criterion mapped to degraded semantics +
  capability-planner expression, with the tightening path pinned in code
  comments and EXPECTATIONS.
- REAL fixture discipline is structural (staleness + static-ELF gates),
  not documentation, after three same-type accidents.
- §10 verdict (ADR 0001 Amendment A4): `x86_64-unknown-linux-musl` is the
  canonical `lsguest-init` build target. Measured: true static-PIE (no
  PT_INTERP segment), musl-target unit tests 19/19, and the musl witness
  passing the live REAL suites (cancellation 4/4 @10.9s, lifecycle 11/11,
  exec 4/4). The interim gnu crt-static path is superseded; REAL gates
  resolve the musl artifact path exclusively.
